# Fonts

All of these are used under the SIL Open Font License 1.1
(https://openfontlicense.org), in their heaviest weight. They are the fonts the
numbers on the dice can be set in. The numbers on the dice are cut from the
font files (`npm run glyphs`), and Settings shows each font's name in the font
itself.

- `Inter-Black.otf` is Inter, © 2016 The Inter Project Authors
  (https://github.com/rsms/inter). The default dice font, and the font of the
  big result numbers.
- `Poppins-Black.ttf` is Poppins, © 2020 The Poppins Project Authors
  (https://github.com/itfoundry/Poppins).
- `Orbitron-Black.ttf` is Orbitron, © 2018 The Orbitron Project Authors
  (https://github.com/theleagueof/orbitron), with Reserved Font Name "Orbitron".
- `PlayfairDisplay-BlackItalic.ttf` is Playfair Display, © 2017 The Playfair
  Display Project Authors (https://github.com/clauseggers/Playfair-Display),
  with Reserved Font Name "Playfair Display". Its numbers on the dice use the
  lining figures (the ones that all stand on the same line).

To add a font, see `src/dice/fonts.ts`.
